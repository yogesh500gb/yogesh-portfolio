YOGESH PORTFOLIO V2 - UPLOAD GUIDE

1. In GitHub, switch to branch: v2-redesign
2. Unzip this package on your computer.
3. In the v2-redesign branch, use Add file > Upload files.
4. Upload ALL files and the assets folder from this package.
5. Existing files with the same names should be replaced.
6. Commit the upload to v2-redesign.
7. Preview/test the branch before merging into main.
