# ARAT — SEO Page Checklist

- [ ] One clear search intent per page
- [ ] Descriptive, unique title and meta description
- [ ] One helpful H1
- [ ] H2s that answer related customer questions
- [ ] Useful original information
- [ ] Real local location/service area information if relevant
- [ ] Relevant internal links
- [ ] Helpful image alt text
- [ ] Clear mobile call to action
- [ ] Fast-loading compressed images
- [ ] Canonical URL and indexability reviewed
- [ ] Google Search Console checked after publishing

No checklist guarantees rankings. Focus on serving real visitors.
